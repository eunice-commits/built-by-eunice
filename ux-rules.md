# UX Rules — Built by Oma

## Purpose
The purpose of this landing page is to guide business owners from curiosity to confidence, and finally to completing the contact form.
Every interaction should reduce friction and encourage visitors to take the next step.
The experience should feel simple, trustworthy, and professional.

## Primary Goal
Encourage visitors to complete the contact form so the conversation can continue on WhatsApp.
Every section should support this single conversion goal.

## User Experience Principles
* Design for clarity before creativity.
* Reduce cognitive load.
* Make every action obvious.
* Guide users naturally through the page.
* Remove anything that distracts from the primary goal.

## Information Hierarchy
Present information in this order:
1. Hero
2. Problem
3. Business Launch Package
4. Pricing
5. How It Works
6. Recent Projects
7. Testimonials
8. About Built by Oma
9. Choose Your Path
10. Frequently Asked Questions
11. Contact Form
12. Footer

*Never change this order unless there is a proven improvement in conversions.*

## Navigation
* Keep navigation simple.
* Navigation should include:
  * Logo (links to top of page)
  * About
  * Package
  * FAQ
  * Contact
* Navigation should remain visible on desktop (sticky).
* On mobile, use a clean hamburger menu.
* The primary CTA button ("Build My Website") should remain visible in the nav alongside these links.

## Call To Action Rules
* Every primary button should scroll smoothly to the contact form.
* Use one consistent primary button style throughout the page.
* Primary CTA text may include:
  * Get My Website
  * Claim My ₦80,000 Package
  * Join the First 10
* The secondary CTA should lead directly to the website course checkout.
* Avoid using more than one competing primary action in the same section, except in the Choose Your Path section, where two equal weight primary actions are intentional. "Build My Website" and "Learn to Build Your Own Website" must carry the same visual prominence there, neither should read as the demoted or secondary option.

## Form Experience
The contact form should feel quick and easy to complete.

### Fields:
* Business Name (required)
* What does your business do? (required)
* Why do you want a website? (required)
* WhatsApp Number (required)
* Email Address (optional)

* Only request information that is necessary to begin the conversation.
* Do not overwhelm visitors with long forms.

## Form Validation
* Show validation messages immediately after an error is detected.
* Explain the error clearly.
* Do not use technical language.
* Retain entered information if validation fails.

## Form Submission
After successful submission:
* Display a confirmation message.
* Automatically redirect visitors to WhatsApp with a prefilled message.
* The confirmation message should reassure the visitor that they are on the list and will be contacted shortly.

## Mobile Experience
* Design for mobile first.
* Buttons should be easy to tap.
* Text should remain readable without zooming.
* Forms should be comfortable to complete using one hand.
* Images should resize without affecting readability.

## Responsive Behaviour
* Desktop may use multiple columns where appropriate.
* Tablet layouts should simplify spacing.
* Mobile layouts should stack all content into a single column.
* Never sacrifice readability for visual complexity.

## Reading Experience
* Use short paragraphs.
* Keep sentences concise.
* Use headings to break content into logical sections.
* Avoid large walls of text.
* Whitespace should improve readability.

## Visual Flow
* Every section should naturally lead into the next.
* Visitors should never wonder what to do next.
* Every major section should include an appropriate call to action where it supports the user journey.

## Trust Building
Trust should increase as visitors move through the page.
Use:
* Real project screenshots
* Real testimonials
* Team introduction
* Clear pricing
* Transparent process
* Professional imagery

*Avoid exaggerated claims or fake urgency.*

## Animations
Animations should enhance the experience, not distract from it.
Recommended animations:
* Fade in
* Slide up
* Gentle hover effects
* Smooth scrolling

*Avoid excessive motion.*
*Performance takes priority over visual effects.*

## Accessibility
* Maintain strong color contrast.
* Use descriptive labels for all form fields.
* Ensure buttons are large enough for touch devices.
* Support keyboard navigation where applicable.
* Provide descriptive alternative text for images.

## Performance
* Prioritize fast loading.
* Optimize all images.
* Lazy load images below the fold.
* Avoid unnecessary scripts or heavy animations.
* The page should remain responsive on slower mobile networks.

## Error Handling
When an error occurs:
* Explain what happened.
* Tell the user how to fix it.
* Do not expose technical details.
* Allow the user to retry without losing entered information.

## Success States
After completing the form, visitors should see:
> "You're on the list. Expect a message or call from us shortly so we can get started."

This message should remain visible before the WhatsApp redirect begins.

## Footer Experience
The footer should provide reassurance rather than ending the conversation.
Include:
* Brand information
* Contact details
* Social media links
* Copyright

*The footer should feel clean and uncluttered.*

## Overall Experience
* Visitors should finish the page feeling informed, confident, and ready to take action.
* The experience should remove uncertainty, answer common questions, and make starting a project feel simple.
* Every interaction should reinforce the professionalism, trustworthiness, and strategic approach of Built by Oma.
