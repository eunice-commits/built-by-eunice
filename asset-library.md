# Asset Library — Built by Eunice

## Purpose
This document lists every asset required to design, build, optimize, and launch the Built by Eunice landing page. It serves as a central checklist to ensure nothing is overlooked during development or before launch.

## Brand Assets

### Logo
Prepare the following versions:
* Primary logo
* Secondary logo
* Icon only logo
* White logo
* Dark logo
* Transparent PNG
* SVG version

### Favicon
Provide:
* 16 × 16
* 32 × 32
* 180 × 180 (Apple Touch Icon)
* Standard favicon package

### Brand Colors
* Primary Brand Color
* Secondary Brand Color
* Accent Color
* Background Color
* Surface Color
* Primary Text Color
* Secondary Text Color
* Success Color
* Warning Color
* Error Color

*These should match the Design System.*

### Typography
* Primary font
* Fallback font
* Heading styles
* Body styles
* Button styles

## Founder & Team Assets
* Professional headshot of Eunice Orji
* Team/group photo (showing the team of product designers, web designers, and digital marketers)
* Lifestyle photo
* Working photo
* Speaking or coaching photo (optional)

*These images should be high quality and optimized for the web.*

## Recent Projects Assets
For every completed project, prepare:
* Website name
* Business category
* Homepage screenshot
* Mobile screenshot
* Desktop screenshot
* Short project description
* Website URL (if publicly accessible)
* Client logo (if approved)

## Testimonial Assets
For every testimonial, collect:
* Client name

* Client photo (optional)
* Business logo (optional)
* Written testimonial
* Permission to publish
* Website link (if applicable)
* Social media link (optional)

*Store backups in a secure cloud location with version control where possible.*

## Asset Quality Standards
Every asset should:
* Be high resolution
* Be optimized for fast loading
* Use consistent branding
* Be approved before publication
* Have a clear filename
* Be stored in an organized folder structure

## Asset Management Principles
* Every asset should have a clear purpose.
* Avoid duplicate files.
* Maintain consistent naming conventions.
* Review and update assets regularly.

*A well organized asset library reduces development time, improves consistency, and supports the long term growth of the Built by Eunice brand.*
