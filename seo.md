# SEO Strategy — Built by Oma

## Purpose
The purpose of this landing page is to attract business owners across Nigeria who are looking for a professional website designer and convert them into qualified leads through the contact form and WhatsApp.
The page should be optimized for both search engines and real users. Every SEO decision should improve discoverability without compromising readability or user experience.

## Primary Goal
Generate qualified website design leads from Google Search while supporting traffic from TikTok, Instagram, Facebook, LinkedIn, referrals, and influencer campaigns.

## Local SEO
* The page should naturally communicate that Built by Oma serves businesses across Nigeria while maintaining a strong presence in Abakaliki and Ebonyi State.
* *Avoid repeating location keywords unnaturally.*

## Structured Data
Implement structured data using Schema.org. Recommended schema types:
* Organization
* Professional Service
* Local Business
* WebSite
* FAQPage
* BreadcrumbList where applicable

*This improves search engine understanding and eligibility for rich search results.*

## Technical SEO
* Use semantic HTML.
* Enable HTTPS.
* Generate an XML sitemap.
* Include a robots.txt file.
* Use canonical URLs.
* Optimize Core Web Vitals.
* Lazy load below the fold images.
* Avoid duplicate metadata.

## Performance
* Compress all media.
* Minify CSS and JavaScript.
* Optimize fonts.
* Reduce unnecessary third party scripts.
* Prioritize excellent mobile performance.

## Accessibility
* Maintain proper heading hierarchy.
* Provide descriptive form labels.
* Use sufficient color contrast.
* Add meaningful alternative text for images.
* Support keyboard navigation where applicable.

* Organic traffic

*Review these metrics regularly to identify opportunities for improvement.*

## SEO Principles
* Write for people first.
* Optimize for search engines second.
* Use keywords naturally.
* Avoid keyword stuffing.
* Focus on solving real problems for business owners.
* Every page should demonstrate expertise, build trust, and make it easy for visitors to take the next step.
