# Design System — Built by Eunice

## Brand Overview
Built by Eunice helps business owners build a professional online presence through modern, strategic websites.
The design should communicate trust, clarity, professionalism, and simplicity. Every design decision should help visitors understand the offer quickly and feel confident taking the next step.

## Design Principles
Every page should feel:
* Modern
* Premium
* Professional
* Approachable
* Mobile first

*Avoid unnecessary decoration.*
*Clarity always comes before creativity.*

## Visual Style
The visual direction should combine:
* Stripe's clarity
* Framer's modern layouts
* Clean whitespace
* Rounded interfaces
* Soft shadows

*The overall experience should feel premium without feeling intimidating.*

## Color Palette
* **Primary: Amber/Gold**
  Used for primary buttons, links, highlights, important actions.
* **Secondary: White**
  Used as the primary page background.
* **Surface: Light Gray**
  Used for cards, testimonials, FAQs, and feature blocks.
* **Text — Primary: Near Black**
* **Text — Secondary: Dark Gray**
* **Text — Muted: Medium Gray**
* **Success: Green**
  Used only for confirmation messages and completed actions.
* **Warning: Amber**
  Used only for promotional notices and urgency.
* **Error: Red**
  Used only for validation and form errors.

## Typography
* Modern, clean, highly readable, professional.
* Headings should be bold and confident.
* Body text should prioritize readability over decoration.
* Paragraphs should remain short.
* Never use large blocks of text.

## Buttons
* **Primary Button**
  Solid primary color. Rounded corners. Large enough for comfortable tapping on mobile.
  *Examples: Get My Website, Claim My ₦80,000 Package, Join the First 10*
* **Secondary Button**
  Outlined style. Used only for secondary actions.
  *Example: Learn to Build Your Own Website*
* **Path Cards (Two Paths section)**
  Both paths ("Build My Website" and "Learn to Build Your Own Website") must use equal visual weight, same card size, same styling treatment, same button prominence. Neither should look like the cheaper or lesser option. This section is a fork between two different outcomes, not a pricing tier comparison.

## Cards
* Cards should have rounded corners, soft shadows, generous spacing, no heavy borders.
* Use cards for: features, testimonials, pricing, FAQs, recent projects, and the two path options.

## Icons
* Use clean outline icons. Icons should support the content, not dominate it.
* *Examples: Website, Google, SEO, Payment, Support, Mobile*

## Images
* Only use real images. Preferred assets include website screenshots, client logos, founder photo, project previews.
* *Avoid stock photos whenever possible.*

## Spacing
* Every section should breathe.
* Maintain generous vertical spacing.
* Keep content within a centered container.
* Avoid cramped layouts.

## Layout
* **Desktop**
  Maximum content width should remain comfortable for reading. Use two column layouts where appropriate.
* **Mobile**
  Single column. Content should stack naturally. Buttons should span the available width where appropriate.

## Animations
* Animations should be subtle.
* Use: fade in, slide up, gentle hover effects.
* Avoid flashy or distracting animations.
* *Performance is more important than visual effects.*

## Forms
* Input fields should be large, simple, easy to complete.
* Labels should remain visible.
* Validation messages should be clear.

## Testimonials
Display testimonials in clean cards. Each testimonial should include client photo where available, business name, client name, review.

## Recent Projects
Show website previews inside clean cards. Each project should include homepage preview, business name, industry, short description.

## Accessibility
* Maintain strong contrast between text and backgrounds.
* Ensure buttons are easy to tap on mobile.
* Support keyboard navigation where applicable.
* Use descriptive labels for all form fields.

## Mobile First
* Every design decision should prioritize mobile users.
* Navigation should remain simple.
* Images should scale correctly.
* Buttons should be easy to tap.
* Forms should require minimal effort to complete.

## Reusable Components
* Hero Section
* Problem Section
* Feature Grid
* Pricing Card
* Process Timeline
* Recent Projects Grid
* Testimonial Cards
* Path Card (used for the Two Paths section)
* About Section
* FAQ Accordion
* Contact Form
* Footer

*These components should be reusable across future Built by Eunice projects to maintain visual consistency and reduce development time.*

## Overall Experience
* Visitors should feel that Built by Eunice is trustworthy, strategic, and professional within the first few seconds of landing on the page.
* Every page should guide visitors naturally toward taking action without feeling overwhelming or overly sales focused.
